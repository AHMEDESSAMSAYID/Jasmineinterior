# جاسمين للتشطيبات والتجهيزات — الموقع

موقع تعريفي لقسم التشطيبات والتجهيزات في شركة جاسمين للاستيراد والتصدير —
**نسختان**: عربية (RTL) وإنجليزية (LTR)، تسع صفحات لكل لغة، بقائمة تنقّل
وقوائم منسدلة ومبدّل لغة في أعلى كل صفحة.

موقع ثابت (Static) بالكامل — لا يحتاج خادماً ولا قاعدة بيانات ولا أي مكتبات خارجية،
عدا خطوط Google.

---

## ⚙️ أول خطوة: ملف `env.js`

**كل الأرقام والروابط في ملف واحد: `env.js` في جذر المشروع.**
افتحه، ضع كل قيمة بين علامتي التنصيص أمام اسمها، واحفظ.
لا تحتاج فتح أي ملف آخر إطلاقاً.

```js
window.ENV = {
  WHATSAPP_MAIN: "905321234567",
  TIKTOK:        "https://tiktok.com/@...",
  INSTAGRAM:     "https://instagram.com/...",
  ...
};
```

كل قيمة متغيّر مستقل باسم واضح، مقسّمة إلى ستة أقسام داخل الملف:

| القسم | المتغيرات |
|---|---|
| ١ · واتساب | `WHATSAPP_MAIN` · `PARTNER_1_WHATSAPP` · `PARTNER_2_WHATSAPP` |
| ٢ · السوشيال ميديا | `TIKTOK` · `INSTAGRAM` · `X` · `FACEBOOK` · `LINKEDIN` · `YOUTUBE` · `TELEGRAM` |
| ٣ · التواصل | `EMAIL` · `PHONE` · `WORK_HOURS` · `MAPS_URL` |
| ٤ · العنوان | `ADDRESS_STREET` · `ADDRESS_DISTRICT` · `ADDRESS_REGION` |
| ٥ · بيانات الشركة | `COMPANY_LEGAL_NAME` · `FOUNDED_YEAR` · `TAX_NUMBER` · `TAX_OFFICE` |
| ٦ · الشريكان | `PARTNER_1_NAME` · `PARTNER_1_EMAIL` · `PARTNER_1_PHOTO` · `PARTNER_2_NAME` · `PARTNER_2_EMAIL` · `PARTNER_2_PHOTO` |

قواعد مهمة:

- **أرقام الواتساب** تُكتب بالصيغة الدولية **بدون `+` وبدون مسافات أو شرطات**.
  مثال تركي: `905321234567` — مثال سعودي: `966501234567`.
  الموقع يبني رابط `https://wa.me/…` بنفسه.
- **روابط السوشيال ميديا** تُكتب كاملة مع `https://`.
- **أي قيمة تتركها فارغة (`""`)**:
  - تختفي أيقونة السوشيال ميديا من قسم التواصل.
  - يظهر في التذييل عنصر نائب ذهبي مثل `[رابط-تيك-توك]` ليسهل العثور عليه.
  - البيانات النصية يبقى مكانها بالشكل المنقّط `[هكذا]`.
  - إن كان `WHATSAPP_MAIN` فارغاً، يختفي الزر العائم وتتحول أزرار الواتساب
    إلى روابط لصفحة «تواصل معنا».

> **لماذا `env.js` وليس `.env`؟**
> الموقع صفحات ثابتة تُفتح مباشرة في المتصفح بلا خادم ولا أدوات بناء،
> والمتصفح لا يستطيع قراءة ملف `.env` بهذه الطريقة. ولذلك الملف بامتداد
> `.js` لكنه يُملأ بنفس بساطة `.env`: اسم المتغيّر ثم قيمته.

## 📁 بنية الموقع

الموقع تسع صفحات، لكل قسم صفحته المستقلة:

```
index.html                 الرئيسية              ← النسخة العربية
about.html                 من نحن + فريق العمل (‎#team)
process.html               آلية العمل + الجدول الزمني + الأسئلة الشائعة
shipments.html             سجل الشحنات
contact.html               تواصل معنا
products/
  index.html               مجالات التوريد — نظرة عامة
  bathroom.html            تجهيزات الحمام
  hospitality.html         تجهيزات المطاعم والفنادق
  finishes.html            التشطيبات والإكسسوارات

en/                        ← النسخة الإنجليزية (نفس البنية بالضبط)
  index.html · about.html · process.html · shipments.html · contact.html
  products/  index.html · bathroom.html · hospitality.html · finishes.html

env.js                     ← الأرقام والروابط (هذا هو الملف الذي تعدّله)
assets/
  css/styles.css           التنسيقات
  js/layout.js             ← الهيدر والتذييل والقائمة (مصدر واحد لكل الصفحات)
  js/site.js               يقرأ env.js ويملأ الصفحات + أيقونات SVG
  img/logo-mark.svg        أيقونة المتصفح فقط (اللوجو نفسه مرسوم بـ CSS)
  team/                    الصور الشخصية
```

### اللغتان

النسخة العربية في جذر المشروع، والإنجليزية في مجلد `en/` بنفس أسماء الملفات.
مبدّل اللغة في أعلى كل صفحة ينقلك إلى **نفس الصفحة** في اللغة الأخرى.

نصوص الهيدر والتذييل والقائمة معرّفة باللغتين في `assets/js/layout.js`
(القاموس `T` والمصفوفتان `NAV_AR` و `NAV_EN`)، ويختار الملف اللغة تلقائياً
من `<html lang>`. الملف نفسه — `styles.css` و `site.js` و `env.js` — يخدم
اللغتين؛ التنسيقات تستخدم الخصائص المنطقية (`inset-inline-start` وأخواتها)
فتنعكس مع الاتجاه دون قواعد منفصلة.

بعض القيم لها نسخة إنجليزية في `env.js` بلاحقة `_EN`:
`ADDRESS_STREET_EN` · `ADDRESS_DISTRICT_EN` · `ADDRESS_REGION_EN` ·
`PARTNER_1_NAME_EN` · `PARTNER_2_NAME_EN`.

### القائمة الرئيسية

القائمة معرّفة في **مكان واحد فقط**: المصفوفة `NAV` في أول ملف
[`assets/js/layout.js`](assets/js/layout.js). أي تعديل فيها — إضافة صفحة،
تغيير اسم قسم، إعادة ترتيب — ينعكس تلقائياً على الصفحات التسع وعلى قائمة
الجوال والتذييل. لا تحتاج فتح كل صفحة على حدة.

بنية القائمة الحالية:

| العنصر | قائمة منسدلة |
|---|---|
| الرئيسية | — |
| مجالات التوريد | جميع المجالات · تجهيزات الحمام · تجهيزات المطاعم والفنادق · التشطيبات والإكسسوارات |
| آلية العمل | — |
| لماذا نحن | — |
| الشركة | من نحن · فريق العمل · سجل الشحنات |
| تواصل معنا | — |

### إضافة صفحة جديدة

1. انسخ أي صفحة موجودة كنقطة بداية (مثلاً `shipments.html`).
2. غيّر `<title>` و `<meta name="description">` والمحتوى داخل `<main>`.
3. أضف سطرها في `NAV` داخل `assets/js/layout.js`.
4. إن كانت الصفحة داخل مجلد فرعي، اضبط `window.SITE_BASE = "../";`
   في آخر الصفحة (كما هو الحال في صفحات `products/`).

## 🎨 الهوية البصرية

الموقع مبني على كحلي غامق وذهبي، والأقسام تتبادل بين داكن وفاتح ليكون
للصفحة إيقاع بصري. الألوان معرّفة كلها في أول `assets/css/styles.css`:

```css
--night:   #0E1620;   /* كحلي غامق — الهيرو والفوتر والأقسام الداكنة */
--night-3: #1D2C3F;   /* قسم الدعوة النهائية */
--gold:    #C39A4E;   /* الذهبي الأساسي */
--gold-lt: #E0BE7C;   /* ذهبي فاتح للنصوص على خلفية داكنة */
--gold-ink:#8A6A2E;   /* ذهبي داكن يُقرأ على الخلفيات الفاتحة */
--paper-2: #F4F5F7;   /* رمادي فاتح جداً للأقسام الفاتحة */
```

الخطوط: **Cairo** للعناوين (700/800) و **Almarai** للنصوص.

اللوجو مرسوم بـ HTML و CSS — مربع بحدّ ذهبي بداخله حرف `J`، وبجانبه
`JASMINE` وتحتها اسم القسم. لا يعتمد الموقع على أي ملف صورة إطلاقاً.

## 💻 التشغيل محلياً

انقر مرتين على `index.html` لفتحه في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
