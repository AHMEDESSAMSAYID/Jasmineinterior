# جاسمين للتشطيبات والتجهيزات — الموقع

موقع تعريفي من صفحة واحدة (عربي، RTL) لقسم التشطيبات والتجهيزات في شركة جاسمين للاستيراد والتصدير.

## الملفات

- `index.html` — الموقع كاملاً (HTML + CSS + JS في ملف واحد، بدون أي اعتماديات عدا خطوط Google).
- `.nojekyll` — لتعطيل معالجة Jekyll عند النشر على GitHub Pages.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

Settings → Pages → Source: `Deploy from a branch` → اختر الفرع والمجلد `/ (root)`.

## البيانات الناقصة (Placeholders)

النصوص الموضوعة بين أقواس مربعة `[...]` هي بيانات مؤقتة يجب استبدالها بالبيانات الحقيقية قبل النشر:

| المكان | Placeholder | ملاحظات |
|---|---|---|
| الشريط العلوي / التذييل | `[رقم السجل]` · `[الرقم]` | رقم السجل التجاري والرقم الضريبي وعضوية غرفة تجارة إسطنبول |
| الهيرو والتذييل | `[٢٠١٧]` | سنة تأسيس الشركة |
| الهيرو | `[٨]` | عدد سنوات الخبرة في التصدير |
| أزرار واتساب | `[رقم-الواتساب]` · `[رقم-الواتساب-٢]` | داخل روابط `https://wa.me/…` — يجب أن يكون الرقم بالصيغة الدولية بدون `+` أو مسافات، مثال: `https://wa.me/905xxxxxxxxx` |
| قسم الفريق | `[الاسم الكامل]` · `[اسم العائلة]` | أسماء الشريكين، مع استبدال مربعات `صورة شخصية` بصور فعلية `<img>` |
| التذييل | `[اسم الشارع ورقم المبنى]` · `[الحي]` · `[المنطقة]` | عنوان المكتب في إسطنبول |

للبحث عن كل ما تبقى منها:

```bash
grep -n '\[[^]]*\]' index.html
```

بعد استبدال أي قيمة، يُفضَّل إزالة `class="fill"` من العنصر حتى يختفي التمييز اللوني والخط المتقطّع المخصص للبيانات المؤقتة.

## ملاحظات أخرى

- رابط «القسم الغذائي» في التذييل يشير حالياً إلى `/` — حدّثه إلى عنوان الموقع الغذائي الصحيح.
- البريد `interiors@jasmine.com` — تأكد من صحته أو استبدله.
- قسم «سجل الشحنات» فارغ عمداً، ويُملأ بالصور وبيانات الشحنات لاحقاً.
