# جاسمين للتشطيبات والتجهيزات — الموقع

موقع تعريفي من صفحة واحدة (عربي، RTL) لقسم التشطيبات والتجهيزات
في شركة جاسمين للاستيراد والتصدير.

موقع ثابت (Static) بالكامل — لا يحتاج خادماً ولا قاعدة بيانات ولا أي مكتبات خارجية،
عدا خطوط Google.

---

## ⚙️ أول خطوة: ملف `config.js`

**كل الأرقام والروابط في مكان واحد: ملف `config.js` في جذر المشروع.**
افتحه، املأ القيم بين علامتي التنصيص، واحفظ. لا تحتاج لمس أي ملف آخر.

```js
whatsapp: "905321234567",     // رقم الواتساب الرئيسي
social: {
  instagram: "https://instagram.com/…",
  linkedin:  "https://linkedin.com/company/…",
  …
}
```

قواعد مهمة:

- **أرقام الواتساب** تُكتب بالصيغة الدولية **بدون `+` وبدون مسافات أو شرطات**.
  مثال تركي: `905321234567` — مثال سعودي: `966501234567`.
- **روابط السوشيال ميديا** تُكتب كاملة مع `https://`.
- **أي قيمة تتركها فارغة (`""`)** لن تظهر في الموقع:
  - أيقونة السوشيال ميديا تختفي تماماً.
  - البيانات النصية يبقى مكانها مؤقتاً بالشكل المنقّط `[هكذا]`.
  - إن كان رقم الواتساب فارغاً، يختفي الزر العائم وتتحول أزرار الواتساب
    إلى روابط لقسم «تواصل معنا».

ما يمكن ضبطه من `config.js`:

| القسم | المحتوى |
|---|---|
| `business` | سنة التأسيس · سنوات الخبرة · السجل التجاري · الرقم الضريبي · غرفة التجارة · البريد · الهاتف · العنوان · رابط الخريطة · رابط القسم الغذائي |
| `whatsapp` | رقم الواتساب الرئيسي لكل أزرار الموقع |
| `team` | اسم كل شريك ومسار صورته ورقم واتسابه |
| `social` | واتساب · إنستغرام · لينكدإن · فيسبوك · تيك توك · يوتيوب · إكس · تيليغرام |

الأيقونات تظهر تلقائياً بالترتيب أعلاه، ويُضاف لها البريد والهاتف والخريطة
إن وُضعت قيمها.

## 🖼️ الصور

ضع الصورتين الشخصيتين في `assets/team/` باسم `partner-1.jpg` و `partner-2.jpg`
(التفاصيل في [`assets/team/README.md`](assets/team/README.md)).

## 📁 بنية المشروع

```
index.html              الصفحة
config.js               ← الأرقام والروابط (هذا هو الملف الذي تعدّله)
assets/
  css/styles.css        التنسيقات
  js/site.js            يقرأ config.js ويملأ الصفحة + أيقونات SVG
  img/logo.svg          اللوجو الكامل (دائرة + JASMINE + السطر السفلي)
  img/logo-mark.svg     الدائرة فقط (أيقونة المتصفح)
  team/                 الصور الشخصية
```

## 🎨 اللوجو

أُعيد رسم اللوجو كملف **SVG** (رسم متجهي) بنفس شكل لوجو الشركة:
دائرة عنّابية بإطار ذهبي داخلي وحرف `J`، ثم كلمة `JASMINE`،
مع تغيير السطر السفلي إلى `INTERIOR FINISHES` بدل سطر قسم اللحوم.

مزايا كونه SVG: يظهر بحدّة تامة على كل الشاشات، وحجمه أقل من ٢ كيلوبايت،
ويمكن تعديل ألوانه أو نصّه بفتح الملف في أي محرر نصوص.

الألوان معرّفة في أول `assets/css/styles.css`:

```css
--maroon: #7A1C26;   /* عنّابي اللوجو */
--gold:   #C9A44C;   /* ذهبي اللوجو  */
--clay:   #8C6F5E;   /* اللون الأساسي للموقع */
```

## 💻 التشغيل محلياً

انقر مرتين على `index.html` لفتحه في المتصفح، أو شغّل خادماً محلياً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## 🚀 النشر على GitHub Pages

`Settings` ← `Pages` ← `Source: Deploy from a branch` ← اختر الفرع والمجلد `/ (root)`.
